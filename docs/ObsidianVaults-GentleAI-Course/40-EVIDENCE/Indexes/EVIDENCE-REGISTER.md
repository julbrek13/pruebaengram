# EVIDENCE REGISTER

## Cómo registrar evidencia

Cada evidencia debe incluir:

- Fecha.
- Bloque del curso.
- Ruta del repo o commit/PR.
- Topic key o ID de Engram.
- Nodo del vault que explica el aprendizaje.
- Resultado verificable.
