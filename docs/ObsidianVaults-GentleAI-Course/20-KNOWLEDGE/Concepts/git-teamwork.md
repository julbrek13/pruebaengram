# Git Teamwork

Git en equipo es comunicación verificable: ramas claras, commits atómicos, PRs revisables y evidencia reproducible.

## Conecta con

- Track activo: [[GE-3-TRACKER]]
- Trazabilidad: [[MASTER-TRACEABILITY]]
- SDD: [[sdd-operating-model]]

## Principios

- No mezclar cambios no relacionados.
- Todo PR debe explicar alcance, verificación y evidencia.
- La rama debe contar una historia entendible.

## Señal de madurez

Un reviewer puede entender qué cambió, por qué, cómo verificarlo y qué queda fuera de alcance.
