# gentle-pi

## Qué es

`gentle-pi` es una capa de disciplina sobre Pi: agrega workflows, convenciones y componentes para operar con más gobernanza (SDD, subagentes, guardrails, skills, routing, etc.).

## Duda frecuente

“Si ya tengo gentle-ai + engram, ¿qué me falta?”

Respuesta docente: puede que ya tengas muchas capacidades, pero `gentle-pi` ordena cómo viven dentro del runtime Pi (packages, extensiones y comportamiento del entorno).

## Regla de onboarding

No instalar por ansiedad. Primero definir dolor operativo real, luego elegir package/extensión.
