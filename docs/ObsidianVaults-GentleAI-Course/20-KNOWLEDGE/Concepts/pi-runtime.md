# Pi Runtime

## Qué es

Pi se enseña como **runtime minimalista y componible** para operar agentes. La analogía útil: se parece a Neovim — viene liviano y lo armás con packages según necesidad.

## Qué NO es

- No reemplaza automáticamente Claude Code u OpenCode.
- No vuelve gratis la inferencia del modelo.
- No garantiza calidad por sí solo.

## Tradeoff clave

- Más libertad de composición y extensiones.
- Más responsabilidad operativa para configurar, gobernar y diagnosticar.
