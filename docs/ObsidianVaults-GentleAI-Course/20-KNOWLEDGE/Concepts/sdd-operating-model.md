# SDD Operating Model

SDD no es burocracia. Es control de riesgo. Se usa cuando el cambio necesita exploración, contrato y verificación antes de ejecutar.

## Modos

- no-SDD: cambios simples y reversibles.
- parcial-SDD: investigación + propuesta + aplicación puntual.
- full-SDD: cambios transversales o con alto costo de error.
