# Learning Notes — Fase 1 (Beginner)

Estas notas resumen aprendizajes prácticos aplicados en este repo.

## 1) Verificar antes de afirmar

- Si no reviso `git status`, memoria previa o archivos reales, puedo tomar decisiones sobre información vieja.
- Práctica aplicada: validar estado de rama, commits y remotos antes de seguir.

## 2) Trazabilidad real > progreso aparente

- Un avance sin contexto se pierde rápido.
- Práctica aplicada: dejar cada hito registrado (README, roadmap, memoria) para poder retomar sin fricción.

## 3) Commits chicos y con intención

- “Un objetivo = un commit” obliga a pensar alcance y reduce errores al revisar.
- Práctica aplicada: separar setup, documentación y flujo en hitos distintos.

## 4) SDD ordena el pensamiento técnico

- Explorar, proponer, especificar y taskear antes de implementar baja retrabajo.
- Práctica aplicada: mantener `sdd-init` y artefactos como base para cambios no triviales.

## 5) AI como copiloto, no piloto automático

- Pedir tareas chicas y validar resultados mejora aprendizaje y calidad.
- Práctica aplicada: usar roadmap por fases y checkpoints con evidencia concreta.
