# Contratos, Firmas y Confidencialidad

> `⚖️ requiere counsel review` en todo el documento. Modelo de compliance, no redacción vinculante.
> Normas de referencia: Ley 25.506 (firma), Ley 24.766 (confidencialidad), Ley 26.994 (Cód. Civ. y
> Com.) `🔎 source to verify`.

## Tipos de contrato relevantes

| Tipo | Uso en Qontera | Cláusulas clave (⚖️) |
|---|---|---|
| Servicios / desarrollo | Contratistas, agencias | Titularidad/cesión, entregables, confidencialidad |
| Licenciamiento | Uso de software propio o de terceros | Alcance de licencia, límites |
| Empleo / contratista | Colaboradores | Titularidad de obra, confidencialidad |
| NDA | Intercambio de info sensible | Objeto, plazo, excepciones |

## Firma electrónica vs. firma digital

- Distinción legal relevante en Argentina (Ley 25.506) `⚖️`.
- Firma **digital** y firma **electrónica** tienen efectos y requisitos distintos; confirmar con
  counsel cuál aplica a cada instrumento.

## Confidencialidad / secreto comercial

- Ley 24.766 como marco de referencia `🔎 source to verify`.
- Definir qué información es confidencial, plazo y excepciones.
- Alinear con `docs/workspace/CROSS_REPO_HANDOFF.md`: handoffs sanitizados, sin secretos ni datos
  privados.

## Cláusulas mínimas recomendadas (modelo, no vinculante)

- [ ] Titularidad / cesión de derechos.
- [ ] Confidencialidad y secreto comercial.
- [ ] Protección de datos personales (si aplica).
- [ ] Ley aplicable y jurisdicción.
- [ ] Firma (electrónica/digital) válida (⚖️).
